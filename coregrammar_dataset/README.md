# Core Grammar Russian Dataset

Скрипт формирует очередь русских предложений для ручного перевода на хакасский. Его цель — не ещё один широкий тестовый набор, а устойчивое обучающее дополнение с бытовой лексикой и конструкциями, которые при буквальном переносе особенно часто дают русскую кальку.

## Почему эти источники

Распределение по умолчанию: Tatoeba — 75%, Common Voice — 15%, MASSIVE — 10%.

- **Tatoeba** даёт большой запас коротких естественных примеров. Скрипт присоединяет официальный `rus_user_languages` и повышает приоритет авторов с уровнем русского `5` (native). Недостаток источника — неоднородное качество, поэтому он проходит строгую фильтрацию.
- **Common Voice sentence collector** полезен как источник произносимых фраз, но содержит литературные и официальные фрагменты. Для него действует усиленный стоп-лист и общий фильтр длины/разметки.
- **MASSIVE ru-RU** хорошо покрывает бытовые команды, вопросы и интенты; сценарий и интент сохраняются в метаданных очищенного кэша.

Ранее переведённые **SMOL** полезны как небольшой набор доменов, но слишком малы для стабилизации базовой грамматики. **FLORES+** — прежде всего контрольный benchmark с более книжным стилем; его `dev`/`devtest` нельзя подмешивать в train. **BOUQuET** специально предназначен для оценки разнообразных регистров, а не как основной train-корпус. Поэтому эти наборы не используются как источники новых строк: их русский текст служит blocklist, чтобы исключить утечку оценки. В конфигурации уже включены основной параллельный корпус, SMOL, FLORES+ и оба split BOUQuET; gated BOUQuET начнёт учитываться после авторизации Hugging Face.

## Установка и запуск

```bash
python -m venv .venv
.venv/bin/pip install -r coregrammar_dataset/requirements.txt

.venv/bin/python coregrammar_dataset/prepare_coregrammar.py \
  --total 100000 \
  --seed 42 \
  --output coregrammar_dataset/output/coregrammar_100000
```

`--total` принимает значения от 1 до 100000. Проверка выполняется до чтения конфигурации и до сетевых запросов. Повторный путь `--output` намеренно не перезаписывается.

Полезные параметры:

```text
--cache-dir PATH       исходные загрузки и очищенный JSONL-кэш
--config PATH          YAML с переопределениями
--strict-quotas        ошибка при любом дефиците исходной квоты
--offline              использовать только локальные источники и кэш
```

Загрузки и обработка исходников потоковые. Очищенный кэш строится с запасом, достаточным для любого допустимого `--total`; следующий запуск с другим размером не скачивает и не фильтрует исходник заново. Сам этап оптимизационного отбора держит очищенный пул в памяти.

## Квоты и конструкции

Целевые проценты переводятся в целые количества методом наибольших остатков. Источники распределены 75/15/10. Конструкции распределены 18/10/8/8/12/12/12/12/5/3 согласно `config.default.yaml`. Маркеры `который`, `чей`, `тот, кто`, `когда`, `пока`, `после того как`, `прежде чем`, `если`, `чтобы`, `потому что`, `хотя`, `у меня есть`, `мне нужно`, `можно`, `нельзя` получают явные метки.

Если источник не достигает квоты, обычный режим добирает сначала из Tatoeba, затем Common Voice и MASSIVE. `--strict-quotas` останавливает запуск с подробным дефицитом. Фактические значения всегда находятся в `quota_report.csv`.

## Результат и контроль качества

Выходная директория публикуется атомарно и содержит:

- `sentences.csv`, `sentences.jsonl` — ровно запрошенное число строк;
- `reserve.csv` — до 20% замен;
- `quota_report.csv`, `rejected.csv`, `near_duplicates.csv`;
- `manifest.json` — seed, размеры, дефициты, ошибки источников и blocklist;
- `README.md` — памятку переводчику.

Перед передачей переводчикам обязательно проверьте `manifest.json:blocklist_failures`. Gated-наборы и приватные репозитории Hugging Face требуют `huggingface-cli login`; скрипт записывает недоступность, а не делает вид, что дедупликация состоялась.

## Тесты

```bash
python -m unittest discover -s coregrammar_dataset/tests -v
```

Тесты не требуют сети и проверяют границы 1/100000, размеры 1/100/3000/10000/100000, округление, фильтры, классификацию, детерминированность, перераспределение, строгий режим, парсеры и полный CLI-проход.
