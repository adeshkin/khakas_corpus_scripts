# Архив

В `legacy_scripts/` находятся старые версии и завершённые одноразовые скрипты.
Они сохранены для истории, но не входят в поддерживаемый рабочий процесс.

Перед повторным использованием проверьте зависимости, пути к данным и формат
ожидаемых таблиц. Архивные файлы могут дублировать более новые инструменты из
корневых тематических каталогов.
