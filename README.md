# khakas_corpus_scripts

Скрипты для сбора, очистки, подготовки и анализа хакасско-русского параллельного и монолингвального корпуса (переводы, обучающие датасеты, статистика).

Большинство скриптов — разовые (one-off) утилиты под конкретную задачу: пути к файлам часто захардкожены внутри (`/home/adeshkin/Downloads/...`), поэтому перед запуском стоит открыть файл и поправить путь под себя.

## Структура

### `collect/` — сбор и скачивание данных
Скачивание датасетов с HuggingFace, определение языка текста, машинный перевод, парсинг локалей Common Voice.
- `download_hf_dataset.py` — скачивает датасеты `khakas-towns-villages` и `khakas-russian-parallel-corpus` с HF.
- `land_id.py` — определение языка текста (fastText language-id).
- `translate_google.py` — перевод слов через Google Translate (для gatitos).
- `common_voice_khakas_locale.py` — парсинг `.ftl`-файлов локализации Common Voice.

### `clean/` — очистка и проверка текста
Поиск "битых"/чужеродных символов, латиница/кириллица, нормализация текста, алфавит.
- `check.py`, `check_symbols.py`, `replace_symbols.py` — поиск и замена проблемных символов в текстах.
- `clean_mono.py` — очистка монолингвального корпуса (смешение алфавитов, дубликаты).
- `clean_uchebniki.py` — очистка текста учебников (детект перечислений и т.п.).
- `khakas_alphabet.py` — эталонный алфавит хакасского языка и проверки по нему.
- `preprocess_text.py` — нормализация текста (на основе пайплайна stopes/NLLB): пунктуация, непечатаемые символы и т.д.

### `prepare/` — подготовка датасетов
Приведение сырых выгрузок (Excel/CSV из акций, переводчиков, smol-датасетов) к финальному виду для перевода/обучения, разбиение на части.
- `prepare_akciya.py`, `prepare_translated_yandex.py`, `prepare_joined_translation_res.py` — сборка результатов переводов от разных переводчиков/источников.
- `prepare_alpaca.py`, `prepare_names.py`, `prepare_towns_villages_geo_names.py`, `prepare_metrics.py` — подготовка вспомогательных датасетов (инструкции, имена, геонимы, метрики).
- `prepare_for_translation.py` — отбор предложений для отправки на перевод (с учётом длины и train/test сплита).
- `prepare_smol.py`, `smol_pull_request_new.py` — подготовка и сверка smol-датасетов (импортируется из `clean/check.py`).
- `pack_uchebniki.py` — упаковка текста учебников в CSV-таблицы для разметки.
- `split_by_parts.py`, `split_into_sents.py` — разбиение текста/таблиц на батчи и предложения.

### `merge_tables/` — объединение и сверка таблиц
Джойны CSV/Excel/текстовых файлов из разных источников в единые таблицы.
- `join.py`, `join_csv.py`, `join_tables.py`, `join_texts.py` — объединение параллельных пар и текстов из разных источников.
- `create_table_pandas.py`, `excel_sheets2csv.py` — сборка таблиц из txt/Excel (напр. "Маленький принц", электронный корпус).
- `find_russian_version.py` — подтягивание русского перевода к хакасским предложениям по параллельному корпусу.

### `analysis/` — статистика и анализ
- `analyze_dataset.py` — длина предложений (в словах) в HF-датасете.
- `get_stats.py` — статистика по символам корпуса.
- `get_info.py` — сверка моно- и параллельных данных TIL-корпуса.

### Уже существующие тематические папки
- `nllb_preprocess/` — отдельный пайплайн очистки/дедупликации/финализации корпуса в стиле NLLB (см. его собственный [README](nllb_preprocess/README.md)).
- `smol/` — скрипты по семейству smol-датасетов: `gatitos/`, `smoldoc/`, `smolsent/`.
- `external_datasets/` — работа с конкретными внешними датасетами (`bouquet`, `wmt24pp`, `averoo_baby_mmlu2`).
- `til_corpus/` — скачивание моно- и параллельного TIL-корпуса (kjh/ru).
- `pdf/` — нарезка и переименование PDF-файлов.
- `parse_dict/` — промпт для LLM-парсинга статей толкового словаря хакасского языка в JSON.
- `scripts-old/` — старые/неактуальные версии скриптов, оставлены для истории.

## Требования

```bash
pip install -r requirements.txt
```

Ключ Yandex.Dictionary API хранится локально в `.env` (в git не попадает, см. `.gitignore`).
